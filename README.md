## Open tools

### [Launchpad](https://github.com/chama-x/launchpad) — the zero-daemon macOS workspace engine

The file system is the UI: Spotlight launches projects, Finder tags show readiness, Quick Look reads the docs. 0 MB idle RAM, pure Python stdlib, plus a workspace contract for AI coding agents (structured context cards, port probing, fail-closed guardrails).

```bash
curl -fsSL https://raw.githubusercontent.com/chama-x/launchpad/main/install.sh | bash
```

### [Paper](https://open-typst.vercel.app) — Typst in the browser

WASM-compiled Typst with live PDF preview and local-first persistence. The same engine generates Black Rock's production vouchers.

### [OpenWorldEye](https://github.com/chama-x/openworldeye) — live geospatial fusion on a WebGL globe

Satellite orbits (SGP4/TLE propagation), live air traffic (ADS-B), and seismic events (USGS), fused into one interactive globe.

## Research

### Spatially-aware generative agents — neuro-symbolic agents in a 3D world

LLMs have no feel for momentum, line-of-sight, or collision. This work splits the loop: the LLM plans asynchronously while a continuous steering layer executes the physics. Formalized in my final-year university research (React Three Fiber world, Yuka steering, decoupled symbolic planning).
